# NEON RUSH 3D

Jogo de corrida arcade 3D para navegador Android, feito com Three.js.

## Jogar
Abra `index.html` em um navegador com internet ou publique a pasta `neon-rush-3d` usando GitHub Pages.

## Controles
- Toque nas setas para mudar de faixa.
- Também aceita deslizar para os lados.
- No computador: setas ou A/D.

## Recursos
- Cenário 3D com estrada noturna, cidade neon e carros 3D.
- Pontuação, velocidade, obstáculos e recorde salvo localmente.
- Interface responsiva para celular.
- Sem instalação de app ou dependências de build; Three.js é carregado por CDN.

## Nota
Esta é uma primeira versão arcade jogável. A renderização 3D requer conexão com a internet para carregar a biblioteca Three.js.
